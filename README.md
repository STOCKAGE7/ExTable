# ExTable - Intelligent PDF Table Extractor

ExTable is a modern, dark-themed desktop application built with Python that intelligently scans PDF files, detects tables, and exports them into clean Excel (.xlsx) spreadsheets.

## Features

- Dark mode interface for comfortable viewing  
- Smart table detection from any PDF file  
- Export selected or all tables to Excel  
- Interactive preview of table content  
- Multi-table and multi-page support  

## Built With

- **Python**
- **Tkinter** – for the graphical interface  
- **pdfplumber** – for PDF table extraction  
- **pandas** and **openpyxl** – for Excel file creation
